# Trilha de Estudos — Qualidade de Software

Trilha de estudos gratuita e interativa sobre Qualidade de Software, organizada em 4 áreas de conteúdo com 31 tópicos.

🔗 **Acesse a trilha:** [caioandrian.github.io/trilha_estudo_qualidade](https://caioandrian.github.io/trilha_estudo_qualidade/)

---

## Conteúdos

| Área | Tópicos |
|---|---|
| Qualidade de Software | O que é QA, mitos sobre qualidade, processos e boas práticas |
| Níveis/Camadas de Teste | Pirâmide de testes, teste unitário, integração, componente, E2E e exploratório |
| Tipos de Teste | Unidade, integração, contrato, API, sistema, aceitação, E2E, funcional, regressão, fumaça, desempenho, carga, estresse, manual e exploratório |
| Técnicas de Teste | Particionamento de equivalência, análise de valor limite, transição de estados, tabela de decisão, caso de uso, pairwise e baseado em experiência |

## Como usar

- Selecione uma área no menu de conteúdos
- Clique em um tópico na barra lateral para abrir o conteúdo
- Leia o material e clique em **Marcar como lido** para registrar o progresso
- O progresso é salvo automaticamente no navegador

## Tecnologias

Site estático — HTML, CSS e JavaScript puro, sem dependências ou build. Deploy via GitHub Actions no GitHub Pages.
